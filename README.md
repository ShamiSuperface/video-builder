# בונה סרטונים

אפליקציית דפדפן שרצה מקומית: בוחרים תיקיית תמונות, מסננים לפי זיהוי פנים, מסדרים לפי תאריך צילום, מוסיפים פילטרים ומעברים, מצמידים חיתוכים לביטים של שיר ומייצאים וידאו. התמונות לא יוצאות מהמחשב.

## הרצה

דרוש Node.js 20 ומעלה ודפדפן Chrome או Edge.

```bash
npm install
npm run dev
```

ואז לפתוח את הכתובת שמודפסת (בדרך כלל http://localhost:5173).

גרסה בנויה מוכנה נמצאת בתיקייה `dist`. אפשר להגיש אותה עם כל שרת סטטי, למשל `npx serve dist`.
(פתיחה ישירה של `dist/index.html` בלחיצה כפולה לא תעבוד, כי הדפדפן חוסם טעינת מודלים מקובץ מקומי.)

## מבנה

- `src/lib/photos.ts` קריאת תמונות ותאריכי EXIF
- `src/lib/faces.ts` זיהוי פנים (face-api, מודלים ב-`public/models`)
- `src/lib/beats.ts` זיהוי טמפו וביטים (spectral flux + מעקב ביטים בתכנות דינמי)
- `src/lib/render.ts` ציור פריימים: פילטרים, זום קן ברנס, מעברים
- `src/lib/captions.ts` כתוביות: ייבוא LRC/SRT, הצמדה לביטים, ציור על הווידאו (כולל עברית)
- `src/Captions.tsx` עורך כתוביות וסנכרון בהקשה
- `src/lib/drafts.ts`, `src/Drafts.tsx` טיוטות: שמירה ב-IndexedDB של הדפדפן (כולל התמונות והשיר), שמירה אוטומטית, פתיחה ומחיקה
- `src/Player.tsx` ניגון וייצוא (MediaRecorder)
